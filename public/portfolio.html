Personal Portfolio

Overview:

This project is a personal developer portfolio designed and built from the ground up to showcase my work, technical skills, and software engineering journey. Designed in Figma and developed using semantic HTML5, modern CSS (Flexbox & Grid), and JavaScript, it features a clean, responsive aesthetic inspired by personal memories and a focus on performance and user experience.

Design Decisions & Rationale:

Color Harmonies:

Rooted in childhood home memories, warm beige and #456882 (teal-slate) form a calming, grounded palette, while energetic coral #e14434 provides clear visual focus on highlighted achievements and takeaways without clutter.

Visual Balance & Contrast:

The soft beige base reduces eye fatigue compared to stark white, while deep slate #35516a provides sufficient contrast on interactive states for accessible navigation.

Technology Stack:

Features:

  • Hero Section - Editorial greeting and animated divider built with Flexbox
  • Interactive Device Tabs - Multi-viewport preview switcher (Mobile, Tablet, Laptop, Desktop)
  • Screenshot Viewer - In-browser responsive gallery with page switching and scrollable preview frame
  • Color Palette System - Visual swatches with hex values, usage roles, and design rationale
  • Accessible Mobile Drawer - Slide-in navigation menu with backdrop overlay and keyboard focus management

Lessons Learned:

  • Built fully responsive layouts from scratch using semantic HTML5, modern CSS Grid, and Flexbox.
  • Designed and implemented custom interactive UI components (device tab switchers, scrollable viewport previews, and accordions) with vanilla JavaScript.
  • Learned to translate Figma wireframes into performant code while establishing a cohesive color palette and visual design system.
  • Implemented accessible navigation patterns including mobile drawers, focus management, and ARIA attributes.
  • Applied SEO best practices, Open Graph metadata for rich social sharing, and continuous deployment workflows with Netlify.
GitHub

The palette is inspired by my childhood home—using warm beige as the primary background and a subtle teal accent to give the site personal meaning and a clean aesthetic.

The layout relies on CSS Flexbox and Grid along with tailored media queries to ensure smooth scaling from mobile devices to desktop screens.

I first prototyped the wireframes and visual hierarchy in Figma and Canva, then translated the components into clean, semantic HTML and CSS.

Form submissions are handled via Web3Forms without needing a backend server, and the site is hosted and continuously deployed via Netlify.
